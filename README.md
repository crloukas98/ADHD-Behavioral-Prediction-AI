# ADHD Behavioral Prediction AI

## Overview

An open-source machine learning project investigating whether behavioral and cognitive features can predict ADHD-related patterns.

## Motivation

Attention Deficit Hyperactivity Disorder (ADHD) is a neurodevelopmental condition involving differences in attention regulation, executive function, and cognitive control.

Machine learning may help identify behavioral patterns associated with ADHD and improve understanding of individual differences.

## Research Question

Can explainable AI models identify behavioral features associated with ADHD?

## Methods

- Data preprocessing
- Exploratory data analysis
- Machine learning classification
- Explainable AI using SHAP

## Technologies

- Python
- Scikit-learn
- XGBoost
- SHAP
- Streamlit

## Disclaimer

This project is a research prototype and is not intended for medical diagnosis.
