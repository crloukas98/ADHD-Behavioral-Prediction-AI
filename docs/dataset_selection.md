# Dataset Selection

## Research Goal

Predict ADHD-related behavioral patterns using machine learning.

## Requirements

The dataset should provide:

- ADHD/control labels
- behavioral measurements
- demographic variables
- open access
- reproducible download process

## Initial Candidate

ADHD-200 Consortium Dataset

Advantages:
- widely cited
- neuroscience relevance
- open science dataset

Challenges:
- heterogeneous sites
- complex structure
- preprocessing requirements

## Decision

The dataset will be inspected before feature selection and modeling.
