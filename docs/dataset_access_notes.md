# ADHD-200 Dataset Access Notes

## Dataset

ADHD-200 Consortium Phenotypic Data

## Purpose

This dataset will be used to investigate whether machine learning models can identify statistical behavioral patterns associated with ADHD classification.

## Data Type

Initial model:

- Phenotypic variables
- Demographics
- Behavioral measurements
- Clinical labels

Excluded:

- MRI imaging data
- fMRI preprocessing
- High-dimensional imaging features

## Data Acquisition Status

Pending official source verification.

## Planned Processing

Raw data:

data/raw/

Processed data:

data/processed/

All transformations will be performed through documented Python scripts.

## Research Limitations

This project does not create a diagnostic tool.

Machine learning predictions represent statistical associations within a research dataset and should not be interpreted as clinical decisions.
