# Dataset

## ADHD-200 Consortium Dataset

## Purpose

The ADHD-200 dataset contains neuroimaging and behavioral data from participants with ADHD and typically developing controls.

This project focuses initially on behavioral and demographic variables.

## Research Goal

Determine whether machine learning models can identify patterns associated with ADHD classification.

## Important Limitations

- ADHD is heterogeneous.
- Behavioral differences are probabilistic, not deterministic.
- Machine learning predictions should not be interpreted as clinical diagnosis.

## Planned Features

Potential features:

- Age
- Sex
- IQ
- Behavioral scores
- Cognitive task measurements

## Target Variable

Binary classification:

0 = Control

1 = ADHD
